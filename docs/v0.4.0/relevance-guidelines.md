# Relevance Guidelines

Grades are 3 (highly relevant), 2 (relevant), 1 (partially relevant), and 0 (not relevant). Reviewers must distinguish project delivery from a summary mention, and employment at an organization from delivery for that organization.

The default workflow is rule-assisted draft → manual review → explicit correction → versioned judgement set. LLMs may assist review but cannot be the unreviewed source of truth.
