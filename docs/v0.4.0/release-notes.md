# ARMIE Retrieval Platform v0.4.0

v0.4.0 establishes the Expert Discovery relevance-engineering foundation: typed domain records, deterministic dataset manifests, 120 labelled query contracts, 0–3 judgement schemas, graded metrics, failure taxonomy, reproducible manifests, and optional Elasticsearch BM25/dense providers alongside the existing FAISS path.

The release does not claim production scale, universal retrieval superiority, a complete Knowledge Graph, automated learning-to-rank, or hosted deployment.
