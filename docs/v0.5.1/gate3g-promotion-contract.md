## Frozen thresholds

- Coverage: 100% terminal items.
- False REQUIRED query and span/assertion rate: 0%.
- False EXCLUDED rate: 0%.
- Final False HARD query rate: 0%.
- Overall role accuracy: ≥85%.
- REQUIRED, EXCLUDED, PREFERRED, CONTEXT_ONLY, UNSUPPORTED, and AMBIGUOUS
  strata: ≥80% each.
- Registry field and canonical-value accuracy: ≥95% where a supported mapping
  is expected.
- Operator/value accuracy: ≥95% where numeric normalization is expected.
- Exact CandidateInterpretation match: ≥80%.
- Supported-constraint precision: ≥95%; supported recall: ≥80%.
- Unsupported preservation: ≥95%.

The zero-safety thresholds protect against hardening context, preference, or
unsupported meaning. Quality thresholds are stage-specific and are not copied
from the historical Gate 3 one-shot contract. Any threshold change invalidates
the benchmark run and requires a new authorized Gate.
