# Gate 2 Start Gate Preflight (Reference Only)

This is an evidence-free entry checklist for a future Gate 2 task. It does
not activate Gate 2 and does not change the current project state.

Before any Gate 2 work starts, the dispatch must reference:

- Project ID: `armie-retrieval-platform`;
- Company OS Core v0.1 reference and the local [Project Adapter](../../company-os/PROJECT_ADAPTER.md);
- current [Project State](../../company-os/PROJECT_STATE.md) and active
  [Work Object](../../company-os/CURRENT_WORK.md);
- a Gate 2 Task Contract with objective, allowed paths/systems, exclusions,
  acceptance criteria, evidence profile, founder acceptance authority, and
  stop condition;
- the relevant Gate 1 Result Package and candidate transition;
- risks, open questions, dependencies, and required Result Package/write-back
  destination.

## Preflight decision

The agent may begin only when every item is present, current, and internally
consistent. If any item is missing or stale, return a blocked preflight result
and request an activated Gate 2 Work Object. Do not infer Gate 2 authorization
from Gate 1 tests, candidate completion, or this checklist.

At completion, the Gate 2 Result Package must record objective evidence,
verification, candidate transition, founder decision required, and structured
write-back to the local Company OS records. This checklist is a reference, not
evidence that Gate 2 has started.
