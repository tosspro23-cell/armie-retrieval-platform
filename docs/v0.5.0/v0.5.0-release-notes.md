# ARMIE Retrieval Platform v0.5.0

## Constraint-aware retrieval

v0.5.0 adds a deterministic structured `RetrievalContract` foundation,
canonical constraint planning, repaired versioned projection evidence, and
native Elasticsearch pre-filtering. The promoted C1 path combines H2 Dense
retrieval with strict no-relaxation eligibility filtering and exposes
constraint provenance, shortfall, and unsupported states in the Workbench.

The Workbench now provides registry-backed industry/exclusion controls,
human-readable must-have filters, C0/C1 strategy identity, and per-result
Constraint Evidence.

## Architecture decision

- **C0:** H2 Dense for unconstrained/free semantic retrieval.
- **C1:** promoted default constrained path: H2 Dense + deterministic native
  pre-filter.
- **C2:** de-prioritized and diagnostic only.
- **C3:** deferred.

## Evaluation and governance

Gate 6D froze the constraint-aware evaluation protocol and promoted C1. The
earlier invalid/inconclusive Gate 6, 6R, 6M, 6A, and 6B runs remain preserved as
governance history; only the repaired Gate 6D evidence is architecture
evidence.

## Known limitations

The supported scope is limited to deterministic `years_experience`, `industry`,
`role`, `location`, `seniority`, approved explicit exclusions, and approved
conjunctions. v0.5.0 does not claim arbitrary natural-language contract
extraction, general temporal or relationship reasoning, delivery/evidence
qualification, graph retrieval, or production C2/C3 support. Dataset v2 is a
controlled synthetic relevance benchmark, not validated real-world
expert-search quality.
